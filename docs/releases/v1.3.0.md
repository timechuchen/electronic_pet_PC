# 兰洛桌宠 v1.3.0

Mac Apple Silicon 与 Windows x64 独立桌宠，新增 ESP32-S3 USB 自动连接。Mac 包包含最新的菜单栏图标优化：18×18 点、Retina 图层及系统深浅色适配。

## 下载

- `Lanluo-Desktop-1.3.0-macOS-AppleSilicon.zip`：macOS 13+、Apple Silicon；解压后打开 `兰洛桌宠.app`，可拖入“应用程序”。
- `Lanluo-Desktop-1.3.0-Windows-x64.zip`：Windows 10/11 x64；完整解压后运行 `Lanluo-1.3.0-Windows/Lanluo.exe`，保留同目录文件。
- `PC-Usage-1.3.0.zh-CN.md`、`PC-AI-Setup-1.3.0.zh-CN.md`、`PC-VRM-FBX-1.3.0.zh-CN.md`：使用、AI 和素材导入说明。
- `PC-Build-Verification-1.3.0.json`：构建与验证范围。
- `SHA256SUMS.txt`：本次附件校验值。

附件来自本地 `releases/v1.3.0` 最新版本，仅将上传文件名改为英文，压缩包内容不变。说明和原验证记录中的中文文件名与上述两个 ZIP 对应。

## 开发板联机

内置 Python 和串口依赖，不需另装 Node.js、Python 或 ffmpeg。连接兼容兰洛固件的 Waveshare ESP32-S3-Touch-AMOLED-1.75C 后，同步画面、聊天气泡、触摸动作和语音；支持断线重连及暂停连接。未连接开发板时仍可独立使用桌宠。

打开新版前先退出旧桌宠和旧 ESP32 服务端。已有兰洛中文固件可继续使用；固件编译步骤见 [ESP32 源码仓库](https://github.com/timechuchen/electronic_pet_ESP32_S3)。本次不分发烧录包。

## 验证与已知限制

19 项 Node、26 项 Python 测试通过。Mac 已完成桌宠启动和开发板联机、语音传输、动作回传及重连验证；图标更新后检查了尺寸、Retina 图层和签名。

Windows 为 Mac 交叉构建，已检查版本、资源和 x64 文件，Windows USB 与中文 SAPI 尚未实机验收。Mac 包采用 ad-hoc 签名，未做 Apple Developer ID 签名或公证；Windows 包未做发布者签名。

AI 需要自行配置 Key；发布附件不含个人 Key 或聊天记录。原 Mac 系统钥匙串超时问题尚未重新验收，模拟聊天和存储测试不代表真实系统密钥保存通过。

仓库保持私有，下载需要相应访问权限。
