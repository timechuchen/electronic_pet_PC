# 兰洛桌宠 v1.3.0 使用说明

本版提供 Mac Apple Silicon 和 Windows x64 两个独立应用，新增 ESP32-S3 开发板 USB 自动连接。不开启开发板也可以继续使用普通桌宠、设置、模型导入和聊天。

## 安装与启动

- Mac：macOS 13+、Apple Silicon。解压 `兰洛桌宠-1.3.0-macOS-AppleSilicon.zip`，将整个 `兰洛桌宠.app` 拖到“应用程序”，再打开。
- Windows：Windows 10/11 x64。完整解压 `兰洛桌宠-1.3.0-Windows-x64.zip`，运行 `Lanluo-1.3.0-Windows/Lanluo.exe`。不要只复制 exe，需保留 resources、DLL 等同目录文件。
- 两个包均内置 Electron、Python 和 pySerial，不需要另装 Python、Node.js 或 ffmpeg。
- 先退出旧版桌宠或旧 ESP32 服务端，再打开新版。新版沿用原 PC 桌宠配置目录 `LanluoDesktop-v1.1`，不要同时运行多个版本。
- Mac 包采用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证；Windows 包未做发布者签名。仅在信任来源时按系统允许流程打开，不需要关闭全局安全保护。

## 自动连接开发板

适用 **Waveshare ESP32-S3-Touch-AMOLED-1.75C**，开发板必须预先烧录本项目兼容的兰洛固件；官方出厂程序和定时器固件不支持这套通信协议。

1. 从 [ESP32 源码仓库](https://github.com/timechuchen/electronic_pet_ESP32_S3) 按 README 编译烧录。当前不提供预编译烧录包；若已烧录此前的兰洛中文固件，不需要为此次 PC 升级重新烧录。
2. 使用 USB 数据线连接开发板，退出串口监视器、其他烧录工具和旧服务端。
3. 启动本版桌宠。初次连接通常需数秒，右键桌宠或打开托盘菜单查看“开发板已连接”和对应串口。
4. 连接后同步角色画面、动作与聊天气泡；开发板触摸动作会传回 PC。“查看开发板预览”可打开小屏画面的预览窗口。
5. 拔插 USB 后会重试连接。菜单“自动连接开发板”可暂停连接、释放串口，再次勾选会恢复；此设置会保存。

PC 通过 USB 发送 320×320 JPEG 和 16 kHz 单声道 PCM。AI 请求在电脑发出，开发板不需要 Wi-Fi，API Key 不写入开发板。

自动发现仅针对原生 ESP32 USB VID/PID `303A:1001`。发现多个匹配设备时不擅自选择，请只保留一块目标板。

## 聊天和语音

- Mac 按 ⌘J，Windows 按 Ctrl+J 打开聊天；⌘, / Ctrl+, 打开设置。
- AI 对话仍需自行配置 DeepSeek Key。本版不附带个人 Key 或聊天记录。
- 连接开发板时，聊天朗读优先从板载扬声器播放，可通过“测试开发板语音”单独检查。
- Mac 板端语音使用系统 `say` 的 `Tingting` 声音和 `afconvert`；Windows 使用系统 PowerShell/.NET `System.Speech` 的中文 SAPI 声音。若缺少中文声音，请在系统中安装兼容的中文语音。
- 没有连接开发板时，朗读仍使用电脑本地声音；板端语音生成或传输失败时，聊天朗读会尝试回到电脑播放。文字和角色互动不依赖语音组件。
- 关闭聊天、清空历史、取消回复和停止朗读等原功能保持原有行为。

## 故障处理

| 情况 | 处理 |
| --- | --- |
| 一直显示等待开发板 | 确认 USB 数据线可传数据，并已烧录兰洛固件；Windows 检查设备管理器 COM 端口 |
| 提示串口被占用 | 退出旧版 ESP32 服务端、其他桌宠实例、ESP-IDF Monitor 或烧录工具 |
| 握手/应答超时 | 等待自动重连；仍无响应时拔插 USB，必要时按 RESET；确认固件匹配 |
| 开发板连接了却没有语音 | 用菜单测试语音，检查系统中文声音；Windows 需要 System.Speech 可见的中文 SAPI 声音 |
| 要编译烧录固件 | 先取消菜单“自动连接开发板”或退出桌宠，释放串口 |
| 没有开发板 | 正常使用桌宠即可，也可取消“自动连接开发板” |

## 验证边界

本次检查结果以同目录 `构建与验证记录.json` 为准。Windows 版本在 Mac 交叉构建，Windows USB、系统中文 SAPI 和权限行为尚未经过 Windows 实机验收。Mac 的真实系统钥匙串存储在旧版曾出现超时，本次保留原实现；使用模拟存储验证聊天流程不代表真实钥匙串问题已解决。

原有 AI 配置和 VRM/FBX 导入说明同目录提供；其中 v1.2.0 字样是原功能说明，当前应用版本为 v1.3.0。用户素材和配置均存放于本机用户目录，应用包不包含测试资料。
